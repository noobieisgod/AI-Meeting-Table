# AI Meeting Table Privacy Policy Site

This folder contains the static privacy policy website for the Android app AI Meeting Table.

## Files

- `index.html`: Public privacy policy page for Google Play.
- `google-play-checklist.md`: Submission checklist and Data Safety consistency notes.

## Publish With GitHub Pages

1. Upload this `docs` folder to a public GitHub repository.
2. Open the repository on GitHub.
3. Go to `Settings`.
4. Open `Pages`.
5. Choose the branch that contains this folder.
6. Choose `/docs` as the publishing folder if GitHub offers that option.
7. Save the settings.
8. Wait for GitHub Pages to publish the site.
9. Copy the published URL into Google Play Console.

Expected URL format:

```text
https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPOSITORY_NAME/
```

## Requirements

The published privacy policy URL should be:

- Publicly accessible
- A webpage, not a PDF
- Available without login
- Not geofenced
- Stable enough to remain available after Google Play submission

The page intentionally uses no analytics, no ads, no tracking scripts, no cookies, and no external fonts.
